# Site Verifier API

API Flask que acessa sites públicos, extrai tabelas com Playwright e exporta dados via JSON.

## Endpoints

- `GET /export/fetch_browser?url=...`

## Deploy

- Suporte a Docker, SQLite ou PostgreSQL.
- Compatível com Render, Railway, Fly.io.

## Requisitos

- Python 3.11+
- Playwright
